# CSET 105 Assignment 3: Rock, Paper, Scissors

## Assignment Info
This assignment involves creating a webpage that hosts a game of rock, paper, scissors using the skills learned from previous lectures.

## Requirements
- Display 3 buttons prompting the user to select rock, paper or scissors
- Computer then randomly selects one of the 3 options
- Display both players' selections
- Increment & display score counter based on which player wins
